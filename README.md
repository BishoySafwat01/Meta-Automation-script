# ⚡ أتمتة صندوق بريد Meta Business Suite & استعادة غير مقروء (V4.4)
### Meta Business Suite Inbox Auto-Responder & Unread Restorer (Python + Playwright + In-Page HUD)

نظام أتمتة ذكي ومتكامل لإدارة صندوق رسائل **Meta Business Suite** (صفحات فيسبوك وإنستغرام) عبر لغة **بايثون (Python)** و **Playwright**، مع واجهة تحكم كاملة مدمجة داخل صفحة فيسبوك مباشرة (**Interactive In-Page HUD**).

---

## 🌟 أبرز المميزات ونظام التحكم (نفس تحكم Tampermonkey وأقوى)

1. **واجهة تحكم زجاجية عصرية مدمجة في صفحة المتصفح (Glassmorphism HUD)**:
   - تظهر نافذة تحكم أنيقة أسفل يسار الصفحة في Google Chrome تدعم اللغة العربية بالكامل (RTL).
   - **سجل عمليات لحظي (Terminal)**: يعرض كل خطوة، فحص، تطابق، أو استعادة مع توقيت زمني دقيق.
   - **إدارة القواعد (Rules Manager)**: يمكنك إضافة، تعديل، تفعيل/تعطيل، أو حذف أي قاعدة رد آلي مباشرة من داخل الصفحة.
   - **أنواع مطابقة متعددة**: `يحتوي (contains)`، `كلمة كاملة (word)`، `مطابقة تامة (exact)`.
   - **الإعدادات البشرية (Human Config)**: تحكم كامل في سرعة الكتابة، فترات التهدئة (Cooldown)، وفترات فحص وضع المراقبة (Standby Monitoring).
   - **أزرار التشغيل والإيقاف**: زر تشغيل فوري وزر إيقاف للطوارئ، مع دعم زر **[Escape]** للإيقاف السريع.

2. **المزامنة الثنائية التلقائية (Two-Way Sync)**:
   - أي قاعدة أو إعداد تقوم بتعديله في واجهة المتصفح يتم حفظه تلقائياً في ملف `config.json` على جهازك عبر بايثون.
   - يمكنك أيضاً تعديل القواعد والردود في ملف `config.json` وسيقوم البرنامج بقراءتها وتطبيقها.

3. **خوارزميات الإنتاج المستقرة (V4.4 Architectural Fixes)**:
   - **Dynamic First-Unhandled Queue**: حل مشكلة اختفاء الصفوف عند تحولها لمقروءة من فلتر "غير مقروء"، حيث يتم فحص أول شات غير معالج دائماً دون حدوث قفز للأرقام أو تخطي.
   - **Expanded Envelope Locator**: العثور الدقيق على زر الظرف (✉) المخصص لاستعادة المحادثة كغير مقروءة عبر مسارات متعددة (شريط الأدوات العلوي، ومجاور زر "تم / Done").
   - **حماية الرسائل الصادرة (Inbound Boundary Guard)**: يتم فحص الرسائل الواردة من العميل **بعد آخر رد من الصفحة فقط**. إذا كان آخر رد صادراً بالفعل من الصفحة، يتخطى الرد فوراً ويعيد الشات كغير مقروء لحماية الشاتات من التكرار.
   - **فلترة الإعلانات الممولة (Clean Ad Filters)**: استبعاد نصوص وإشارات الإعلانات الممولة لتجنب الردود الخاطئة.
   - **محاكاة السلوك البشري (Human Simulator)**: كتابة واقعية بحروف متقطعة داخل محرر Lexical، وتأطير بصري أنيق للشات النشط (باللون السماوي) وفقاعة الرسالة (بالأخضر المنقط).
   - **وضع المراقبة المستمرة (Standby Monitoring)**: عند انتهاء فحص كافة المحادثات غير المقروءة، ينتقل الاسكريبت تلقائياً لوضع المراقبة ويفحص دورياً كل بضع ثوانٍ دون توقف.

## 🚀 طريقة التشغيل خطوة بخطوة

### 1. المتطلبات
تأكد من تثبيت مكتبة `playwright`:
```bash
pip install playwright --break-system-packages
```

### 2. تشغيل Google Chrome بوضع التحكم عن بعد (CDP)
أغلق جميع نوافذ كروم تماماً، ثم افتحه بالأمر التالي في الطرفية (Terminal):

**في لينكس (Linux):**
```bash
google-chrome --remote-debugging-port=9222
```

**أو في ويندوز (Windows CMD / PowerShell):**
```cmd
chrome.exe --remote-debugging-port=9222 --user-data-dir="C:\chrome-debug-profile"
```

### 3. فتح صفحة الصندوق
1. في متصفح كروم المفتوح، ادخل إلى حسابك وافتح صفحة صندوق الرسائل:
   `https://business.facebook.com/latest/inbox/`
2. اضغط يدوياً على فلتر **"غير مقروء" (Unread)** لعرض المحادثات المطلوب الرد عليها.

### 4. تشغيل الاسكريبت في بايثون
في مسار المشروع، شغّل الأمر:
```bash
python3 main.py
```

للبدء الفوري للأتمتة دون الحاجة للضغط على زر البدء في واجهة المتصفح:
```bash
python3 main.py --auto-start
```

## 🎛️ هيكل الملفات
- `main.py`: المشغل الرئيسي بلغة بايثون، مسؤول عن الاتصال عبر CDP، المزامنة، التحديث التلقائي للواجهة، وسجلات الطرفية.
- `bot_script.js`: محرك الأتمتة وواجهة الـ HUD الشاملة ومحاكي التفاعل البشري ومحدد العناصر المتقدم.
- `config.json`: ملف القواعد والإعدادات المخزن محلياً والقابل للتعديل.
- `requirements.txt`: متطلبات التشغيل.

- **من الطرفية (Terminal)**: اضغط على **[Ctrl + C]** للإيقاف الآمن.
